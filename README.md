# ひび手帳

minical・Structured・muute を合わせたような、iPhone の Safari で動く手帳アプリです。
インストール不要。HTML 1枚で、データは端末のブラウザ内（localStorage）に保存されます。

## 4つの画面

| タブ | 元にしたアプリ | できること |
| --- | --- | --- |
| カレンダー | minical | 月表示、複数日にまたがる予定のバー、日本の祝日（振替休日・国民の休日を含む）、日ごとの気分ドット、左右スワイプで月移動、検索 |
| タイムライン | Structured | 1日の予定を時間順に表示（長さに応じたピル型アイコン）、空き時間、現在時刻ライン、完了チェック、終日予定、週ストリップ |
| 日記 | muute | 気持ちを3つまで選ぶ（24種類＋自由入力）、できごとタグ、本文、写真、今日の言葉、書くテーマ |
| ふりかえり | muute（ログ・インサイト） | 直近7日のインサイト文、感情のリズム（7日/30日）、気持ちのランキング、よく書いたこと、よく使う言葉、気分カレンダー |

予定と日記が同じデータを共有しているので、「予定がある日の気分」「タイムラインの完了率」などもインサイトに出ます。
インサイトは端末内で集計しており、外部の AI やサーバーには何も送りません。

## そのほかの機能

- **ひとこと記録** — 日記画面の「いまの気分は？」で、気持ちをタップするだけで保存（取り消しも可）
- **ドラッグで時間変更** — タイムラインのアイコンを長押しして上下に動かす（5分刻み）
- **あとで（Inbox）** — タイムライン右上のトレーのアイコン。Structured のように、提案から選ぶかタイトルを入れて「次へ」→ 所要時間・サブタスク・メモ・色とアイコンを決めて作成。日付を決めるとタイムラインに入る。左にスライドで削除（最後までスライドすると即削除、取り消しも可）
- **予定のテンプレート** — 編集画面の「テンプレートとして保存」→ 新しい予定の上部からワンタップで入力
- **繰り返しの細かい設定** — 曜日指定、毎月の同じ日／第◯◯曜日、毎年、終わりの日、「この回だけ変更」「この回だけ休み」
- **カレンダーの取り込み** — 設定 → .ics ファイルを読み込む（重複は自動で除外）
- **天気の自動記録** — 設定でオンにすると、今日の日記に現在地の天気と気温がつく（GitHub Pages 版のみ）
- **検索の絞り込み** — 気持ち・できごとタグで日記を絞り込み
- **◯年前の今日** — 過去の同じ日の日記を日記画面に表示
- **月報** — ふりかえり → 月ごとの気持ちのバランス、いちばんいい日、写真などをまとめて表示
- **予定と気分** — 予定ごとに「その日」「次の日」の気分の傾向を表示
- **テーマカラー／週の始まり（月曜・日曜）** — 設定から変更
- **バイトの給料計算** — カレンダーの下のカード（設定 → 表示 で出す・出さないを切り替え）。バイト先の名前を含む予定をシフトとして数え、時給・深夜割増・休憩・交通費・締め日から見込みを計算。シフトボードのようなリングで、その月の見込み（うすい緑）と、もう働き終わったシフトの分（緑）がたまっていく様子を表示。月間目標を決めると目標を1周として表示。年の合計と年収の目安も
- **夜勤など日をまたぐ予定** — 終了を開始より前にすると「翌◯時」まで続く予定になる
- **大学の時間割** — タイムライン右上の帽子のアイコン（締め切りが7日以内の課題の数がバッジで出る）。時間割・課題・設定の3つ。授業はタイムラインに自動で入る
- **課題の締め切り** — 大学 → 課題。授業にひもづけて締め切り順に並び、カレンダーに「〆」で表示
- **1年ピクセル** — ふりかえりの下。365マスに1日ずつ気分の色
- **カウントダウン** — 予定の「カウントダウンに表示」をオンにすると、カレンダーの上に「あと◯日」
- **この1週間の動き** — 地図は指で動かせて、2本指・ダブルタップ・＋－ボタンで拡大縮小できる（天気の雨雲レーダーも同じ）。ふりかえりの「この1週間の動き」から。アプリを開いたときや日記を書いたときの場所を記録して（設定 → 場所の記録）、曜日ごとの色の線で地図に表示。移動距離・行った場所の数・いちばんよく行った場所、1日ごとの「どこに何時から何時までいたか」と、その日の気分も一緒に見られる。場所をタップすると「家」「大学」などの名前をつけられる。記録は端末の中だけに保存（iPhoneのブラウザは閉じている間の場所は記録できないので、開いたときの場所をつないで表示）
- **その日の曲** — 日記を書くとき「音楽」の欄に曲名とアーティストを入れると、ジャケット付きの候補が出て、タップでその日の曲として添えられる。候補を選ばずに「この曲を添える」を押しても、裏でジャケットと試聴の音源を探して付ける（Appleの曲の検索を使い、つながらないときはDeezer・MusicBrainzに自動で切り替える。ログインも料金も不要）。ジャケットをぼかした背景のカードで表示し、30秒の試聴や「Spotifyで開く」もできる。最近添えた曲はワンタップで選べる。日記の一覧・検索・月報（この月の曲）にも出る
- **メモリー** — ふりかえりの「メモリー」から、日記に添えた写真をRetro風に振り返る（今週・先週・1か月前・半年前・1年前の今ごろ、月ごと）。写真が画面いっぱいに出て、左上に大きな日付（タップで日付の一覧）。下の目盛りのダイヤルをなぞると写真をめくれて、▶でスライドショー、サイコロでランダムな思い出、左のボタンで写真をシェア。写真の左右タップで前後へ、下にスワイプで閉じる。その日の気持ち・本文・場所・曲も一緒に表示し、曲は試聴もできる。「すべての写真」で月ごとのアルバムも見られる
- **まとめカード** — 月報の「まとめカードを作る」で、その月の気分カレンダー・多かった気持ち・日記の数・写真・今月の曲・動いた距離を1枚の画像（1080×1920、ストーリーにぴったり）に。ポップ／ナイト／クリームの3デザイン。日記の本文は入らないのでシェアしても安心
- **バックアップ** — 毎日決めた時刻をすぎると、端末の中に自動で控えを取る（7日分。設定から戻せる）。さらに、毎日／3日ごと／毎週のお知らせで、ワンタップでiPhoneの「ファイル」に保存できる
- **天気** — カレンダー右上の天気ボタン（いまの天気と気温を表示）から。現在地の気温・体感・湿度・風・気圧・降水・日の出／日の入り・UV、24時間の気温グラフと降水・風、気象庁ナウキャストの雨雲レーダー（過去1時間〜1時間後をアニメーション）、2週間の予報。予報は Open-Meteo（気象庁などのモデル）
- **天気と気分** — 晴れ・くもり・雨の日それぞれの気分と多かった気持ちを、ふりかえりで比べる
- **Wrapped** — ふりかえりの「○年のまとめ」から、1年の日記の数・連続記録・多かった気持ち・気分の1年・よく添えた曲・動いた距離・バイトの時間・思い出の写真を、Spotify Wrapped のようなストーリーでめくって見る
- **乗換案内（のりかえ連携）** — カレンダー・タイムライン右上の電車のボタンで、のりかえ（Yahoo!乗換案内を広告なしで見るアプリ）をひび手帳の中で開き、ひび手帳と同じ見た目で検索。「ひび手帳のタイムラインに追加」で経路が出発〜到着の予定になり、タイムラインでその予定を押すと、乗る電車・番線・乗り換え・運賃・途中の駅が見られる。「のりかえで調べ直す」で同じ区間をすぐ再検索し、そこから追加すると元の予定と入れ替わる（色・持ち物などは引き継ぐ）。のりかえのURLは 設定 → 乗換案内 で変更できる
- **何時に出ればいい？** — 予定に「行き先の駅」を入れると、のりかえで「余裕をもって着く電車」を調べて、タイムラインのその予定の上に「8:00に家を出れば間に合います（名鉄岐阜 8:12発 → 栄 8:47着）」と出す。押すとのりかえで到着時刻指定の検索が開く。家の最寄り駅・家から駅までの時間・余裕は 設定 → 出発時刻のお知らせ
- **今日の画面** — アプリを開くと、あいさつ・天気・つぎの予定（あと○分、出発時刻）・今日の予定・今日明日までのやること・持ち物をまとめた「今日」が最初に出る。設定でオフにできる
- **iPhoneのカレンダーに書き出す** — 設定から、予定（と、やることの締め切り・大学の授業）を .ics にして iPhone の「カレンダー」に取り込める。予定の前の通知（5分〜1時間前）付き
- **やること（To Do）** — カレンダーとタイムラインの一番下に、締め切りのあるやることを「期限切れ／今日まで／明日まで／1週間以内／それ以降／期限なし」に分けて表示。大学の課題もここにまとまる。「いつから（開始）」と締め切りの日・時刻・メモを付けられ、開始から締め切りまでの期間がバーで出る。授業を選ぶと課題になる。締め切りの日はカレンダーに「〆」で出る。上の「やること ○件」を押すとリストまでスクロール。完了は取り消し可能。長押し（または編集画面の「作業する時間を決める」）で、作業する時間をタイムラインに入れられる
- **持ち物リスト** — 予定ごとに持ち物を登録して、当日・前の晩（17時以降は「明日の持ち物」）にタイムラインでチェック。ほかの予定で使った持ち物を候補に出す
- **ロック** — 4けたのパスコードとFace IDで、アプリを開くときにロック（すぐ／1分／5分／15分）。人に見られないための鍵で、データの暗号化ではない
- **集中タイマー** — 予定の画面の「集中タイマー」から開始。全画面の大きな時計（オーロラ／ガラス／カード／フリップ／ロール／ウェーブ／リング／アナログ／ドットの9デザイン、横向きにも対応）。右上のパレットや 設定 → 表示 から、カラー（8種類＋好きな3色を選べるカスタム）・数字の書体・のこり時間／経過時間・背景の動きを細かく変えられる。閉じても計り続け、終了すると実際にかかった時間を記録
- **予定の画面** — Structured 風。色つきの帯に大きなアイコンとタイトル、日付・時間・繰り返しは行をタップして開く。「…」からテンプレート保存・この回だけ休み・削除

## iPhone で使う

1. このリポジトリの **Settings → Pages** で、Source を `Deploy from a branch`、Branch を `main` / `(root)` にして保存
2. 表示された URL（`https://<ユーザー名>.github.io/dairy2/`）を iPhone の Safari で開く
3. 共有ボタン →「ホーム画面に追加」で、アプリのように全画面で使えます（オフラインでも起動します）

## データについて

- 保存先はその端末・そのブラウザだけです。別の端末とは同期しません。
- 設定（歯車）→「バックアップをコピー／ファイルに保存」で JSON を書き出し、「復元」で読み込めます。
- 初回はサンプルの予定と日記が入っています。設定または画面上の「サンプルを消す」で削除できます。

## ファイル

- `index.html` — アプリ本体（HTML / CSS / JS をすべて含む）
- `manifest.webmanifest`, `icons/` — ホーム画面追加用
- `sw.js` — オフライン用のキャッシュ
