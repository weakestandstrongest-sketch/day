# ひび手帳

minical・Structured・muute を合わせたような、iPhone の Safari で動く手帳アプリです。
インストール不要。HTML 1枚で動き、データは端末のブラウザの中（IndexedDB と localStorage）に保存されます。Google でログインすると、Google ドライブにも自動で保存できます。

iOS アプリ版（Capacitor）もあり、ウィジェット・アラーム・Face ID など iPhone の機能が使えます（[iOS アプリ版](#ios-アプリ版capacitor署名なし-ipa)）。

## 4つの画面

| タブ | 元にしたアプリ | できること |
| --- | --- | --- |
| カレンダー | minical | 月表示、複数日にまたがる予定のバー、日本の祝日（振替休日・国民の休日を含む）、日ごとの気分ドット、日ごとの収支（家計簿）、左右スワイプで月移動、2本指で広げる・縮めるでマスの大きさを3段階に切り替え、カウントダウン、やること |
| タイムライン | Structured | 1日の予定を時間順に表示（長さに応じたピル型アイコン）、空き時間、現在時刻ライン、完了チェック、終日予定、週ストリップ、24時間の円のタイムライン、今日の習慣、持ち物 |
| 日記 | muute | 気持ちを3つまで選ぶ（24種類＋自由入力）、できごとタグ、本文、写真、その日の曲、天気、今日の言葉、書くテーマ |
| ふりかえり | muute（ログ・インサイト） | 直近7日のインサイト文、感情のリズム（7日/30日）、気持ちのランキング、よく書いたこと、よく使う言葉、気分カレンダー、日記の連続記録、予定の完了率、メモリー、月報、1年ピクセル、Wrapped |

予定と日記が同じデータを共有しているので、「予定がある日の気分」「タイムラインの完了率」などもインサイトに出ます。
インサイトは端末内で集計しており、外部の AI やサーバーには何も送りません。

## 画面の端からスワイプして開くアプリ

画面の左端から右へ、または右端から左へスワイプすると、ほかのアプリが画面いっぱいに出ます。出した状態でもう一度同じ向きにスワイプすると、さらに奥のアプリが開きます。

| タブ | 左端から右へ | 右端から左へ |
| --- | --- | --- |
| カレンダー | one（今日やることを1つだけ）→ もう一度で しずく（oneの左端から） | 計算機 → もう一度で Mathspace |
| タイムライン | アラーム → もう一度で 候 KŌ | 無音カメラ → もう一度で 写真をPDFに |
| 日記 | Orbit（ブラウザ・アプリ版のみ） | Gyoukai（業界研究・アプリ版のみ） |
| ふりかえり | Jam（サークル・部活の連絡・アプリ版のみ） | チューナー（チューナー・メトロノーム・コード・純正律） |

## 機能

### 予定・カレンダー

- **予定の画面** — Structured 風。色つきの帯に大きなアイコンとタイトル、日付・時間・繰り返しは行をタップして開く。時間の行で「終了日」を選ぶと、10/14 13:00〜10/17 11:00 のように日をまたぐ予定にでき、カレンダーに帯で表示される（日をまたぐ予定はカレンダーだけに表示）。「表示する場所」で、カレンダーとタイムラインの両方／カレンダーだけ（給料日・メモなど）／タイムラインだけ（ルーティン）を選べる。「…」からテンプレート保存・この回だけ休み・削除
- **夜勤など日をまたぐ予定** — 終了を開始より前にすると「翌◯時」まで続く予定になる
- **繰り返しの細かい設定** — 曜日指定、毎月の同じ日／第◯◯曜日、毎年、終わりの日、「この回だけ変更」「この回だけ休み」
- **予定のテンプレート** — 編集画面の「テンプレートとして保存」→ 新しい予定の上部からワンタップで入力
- **カレンダーの大きさ** — iOS のカレンダーのように、2本指で広げる・縮めると「点だけの小さい表示 → いつもの表示 → 予定がたくさん見える大きい表示」の3段階で切り替わる（大きい表示は画面の幅いっぱいにマスを大きくし、予定名を2行まで表示）。指の動きに合わせて週の行と下のカードが広がる・縮み（transform だけで動かし、画面の組み直しをしない）、離すと前の表示がふわっと消えながら、各行が新しい大きさの位置へなめらかに移る
- **カウントダウン** — 予定の「カウントダウンに表示」をオンにすると、カレンダーの上に「あと◯日」
- **検索** — カレンダー右上の虫眼鏡。予定・日記を探せて、気持ち・できごとタグで日記を絞り込める
- **カレンダーの取り込み** — 設定 → .ics ファイルを読み込む（重複は自動で除外）
- **iPhoneのカレンダーに書き出す** — 設定から、予定（と、やることの締め切り・大学の授業）を .ics にして iPhone の「カレンダー」に取り込める。予定の前の通知（5分〜1時間前）付き
- **ショートカットから予定を入れる** — `?add=1&title=…&date=…&start=…&end=…&allday=…&memo=…` の URL で、内容が入った予定の画面が開く（保存は押したときだけ）。`?add=1&q=明日15時から17時までバイト` のように文1つでも読み取る。ショートカットが Safari で開いたときは、Google ドライブを通してホーム画面のひび手帳に届く

### タイムライン

- **ドラッグで時間変更** — タイムラインのアイコンを長押しして上下に動かす（5分刻み）
- **線と色** — 時間が進むにつれて線に色がつき、まだ始まっていない予定は黒い丸にアイコンだけ色がつく
- **24時間の円のタイムライン** — タイムラインのつまみを下に引くと、予定の弧・空き時間・今の針・次の予定までを円で表示
- **あとで（Inbox）** — タイムライン右上のトレーのアイコン。Structured のように、提案から選ぶかタイトルを入れて「次へ」→ 所要時間・サブタスク・メモ・色とアイコンを決めて作成。日付を決めるとタイムラインに入る。左にスライドで削除（最後までスライドすると即削除、取り消しも可）。右側の「ほしいもの」は[お金](#お金家計簿バイトほしいもの)を参照
- **持ち物リスト** — 予定ごとに持ち物を登録して、当日・前の晩（17時以降は「明日の持ち物」）にタイムラインでチェック。ほかの予定で使った持ち物を候補に出す
- **何時に出ればいい？** — 予定に「行き先の駅」を入れると、のりかえで「余裕をもって着く電車」を調べて、タイムラインのその予定の上に「8:00に家を出れば間に合います（名鉄岐阜 8:12発 → 栄 8:47着）」と出す。押すとのりかえで到着時刻指定の検索が開く。家の最寄り駅・家から駅までの時間・余裕は 設定 → 出発時刻のお知らせ
- **今日の画面** — アプリを開くと、あいさつ・天気・つぎの予定（あと○分、出発時刻）・今日の予定・今日明日までのやること・今日の習慣・持ち物をまとめた「今日」が最初に出る。設定でオフにできる

### やること・大学

- **やること（To Do）** — カレンダーとタイムラインの一番下に、締め切りのあるやることを「期限切れ／今日まで／明日まで／1週間以内／それ以降／期限なし」に分けて表示。大学の課題もここにまとまる。「いつから（開始）」と締め切りの日・時刻・メモを付けられ、開始から締め切りまでの期間がバーで出る。授業を選ぶと課題になる。締め切りの日はカレンダーに「〆」で出る。上の「やること ○件」を押すとリストまでスクロール。完了は取り消し可能。長押し（または編集画面の「作業する時間を決める」）で、作業する時間をタイムラインに入れられる
- **やることのくり返し** — 毎日・毎週・2週間ごと・毎月。完了にするか締め切りが過ぎると次の回が出る。「いつまでくり返す」で学期の終わりなどまでにできる
- **大学の時間割** — タイムライン右上の帽子のアイコン（締め切りが7日以内の課題の数がバッジで出る）。時間割・学期と休み・課題・設定の4つ。授業はタイムラインに自動で入る
  - **学期ごとの時間割** — 前期・後期などの学期を作って、それぞれに期間と時間割を持たせる。日付が学期に入ると、その学期の時間割が自動でタイムラインに入る（学期の間の夏休み・春休みは授業が出ない）。時間割の上のボタンで学期を切り替え、前の学期の時間割をコピーもできる
  - **学期の途中の休み** — 冬休み・大学祭などを学期の中に「休み」として追加すると、その間は授業が出ない。カレンダーとタイムラインに休みの名前が出る
  - **休講・振替** — タイムラインの授業をタップすると、その回だけ休講にしたり、別の日・時限に振り替えたりできる。休講にした回は線を引いて残るので、タップして取り消せる。授業の編集画面から補講も追加できる
  - **日ごとの変更** — 「祝日だけど月曜の授業がある日」（振替授業日）や「大学祭で授業なし」（休講日）を日付ごとに決められる
  - **集中講義・オンデマンド** — 時間割の下に一覧と追加ボタン。集中講義は授業の日（1日中もOK）を決めるとタイムラインに入り、オンデマンドは時間割に出さずに課題だけ管理できる
- **課題の締め切り** — 大学 → 課題。授業にひもづけて締め切り順に並び、カレンダーに「〆」で表示。毎週の課題を学期の終わりまでくり返して追加することもできる

### 日記・気持ち

- **ひとこと記録** — 日記画面の「いまの気分は？」で、気持ちをタップするだけで保存（取り消しも可）
- **書きかけの日記** — アプリが閉じられても、書きかけを戻せる
- **気持ちのない日記** — 気持ちをつけずに書いた日記は、その日の前（なければ次）の日記の気持ちで表示する
- **◯年前の今日** — 過去の同じ日の日記を日記画面に表示
- **天気の自動記録** — 設定でオンにすると、今日の日記に現在地の天気と気温がつく（GitHub Pages 版のみ）
- **その日の曲** — 日記を書くとき「音楽」の欄に曲名とアーティストを入れると、ジャケット付きの候補が出て、タップでその日の曲として添えられる。候補を選ばずに「この曲を添える」を押しても、裏でジャケットと試聴の音源を探して付ける（Appleの曲の検索を使い、つながらないときはDeezer・MusicBrainzに自動で切り替える。ログインも料金も不要）。ジャケットをぼかした背景のカードで表示し、30秒の試聴や「Spotifyで開く」もできる。最近添えた曲はワンタップで選べる。日記の一覧・検索・月報（この月の曲）にも出る
- **写真** — 長い辺 2048px・画質85% で保存し、一覧やアルバムには小さな版を使う。写真は容量の大きい保存場所（IndexedDB）に入り、画面に出るものだけを読み込むので、何千枚あってもすぐ開く

### ふりかえり・思い出

- **インサイト** — 日記の連続記録、予定の完了率、日記を書く時間帯、曜日ごとの気分、「今月の予定」（終わった予定の割合と、予定の多い日のカレンダー）
- **予定と気分** — 予定ごとに「その日」「次の日」の気分の傾向を表示
- **天気と気分** — 晴れ・くもり・雨の日それぞれの気分と多かった気持ちを比べる
- **月報** — 月ごとの気持ちのバランス、いちばんいい日、写真などをまとめて表示
- **まとめカード** — 月報の「まとめカードを作る」で、その月の気分カレンダー・多かった気持ち・日記の数・写真・今月の曲・動いた距離を1枚の画像（1080×1920、ストーリーにぴったり）に。ポップ／ナイト／クリームの3デザイン。日記の本文は入らないのでシェアしても安心
- **メモリー** — 日記に添えた写真をRetro風に振り返る（今週・先週・1か月前・半年前・1年前の今ごろ、月ごと）。写真が画面いっぱいに出て、左上に大きな日付（タップで日付の一覧）。下の目盛りのダイヤルをなぞると写真をめくれて、▶でスライドショー、サイコロでランダムな思い出、左のボタンで写真をシェア。写真の左右タップで前後へ、下にスワイプで閉じる。その日の気持ち・本文・場所・曲も一緒に表示し、曲は試聴もできる。「すべての写真」で月ごとのアルバムも見られる
- **1年ピクセル** — ふりかえりの下。365マスに1日ずつ気分の色
- **Wrapped** — 「○年のまとめ」から、1年の日記の数・連続記録・多かった気持ち・気分の1年・よく添えた曲・動いた距離・バイトの時間・思い出の写真を、Spotify Wrapped のようなストーリーでめくって見る

### 場所・天気・乗換

- **この1週間の動き（MOVE）** — ふりかえりから。move アプリと同じ画面（大きな見出し・週の帯・地図・数字・滞在の長さに合わせた色つきカプセルを点線でつなぐタイムライン・いちばん下に「いまここを記録」）
  - 今日の日記を書くと、その場所が自動で記録される（はじめからオン。日記を書いた場所には「日記」の印がつく）。アプリを開いたときにも記録できる（設定 → 場所の記録）
  - 地図は指で動かせて、2本指・ダブルタップ・＋－ボタンで拡大縮小できる。場所と場所の間は道に沿った線で描き（歩き・自転車・車を速さで見分ける）、のりかえで予定に入れた電車は途中の駅を通る線にする。位置が大きく飛んだ記録や誤差の大きい記録は線に使わない
  - 移動距離・行った場所の数・いちばんよく行った場所、1日ごとの「どこに何時から何時までいたか」と、その日の気分も一緒に見られる。場所をタップすると「家」「大学」などの名前をつけられる
  - **今までの軌跡をゆっくりたどる** — 記録した場所を古い日から順に、地図の上で動く点が追いかける（速さ・再生する時期を選べる）
  - 記録は端末の中に保存し、Googleでログインしていると、同じアカウントの **move**（ボタンを押して場所を記録するアプリ）とドライブの `hibi-moves.json` で分け合う（iPhoneのブラウザは閉じている間の場所は記録できないので、開いたときの場所をつないで表示。アプリ版は閉じているあいだも記録できる）
- **天気** — カレンダー右上の天気ボタン（いまの天気と気温を表示）から。現在地の気温・体感・湿度・風・気圧・降水・日の出／日の入り・UV、24時間の気温グラフと降水・風、気象庁ナウキャストの雨雲レーダー（過去1時間〜1時間後をアニメーション）、2週間の予報。予報は Open-Meteo（気象庁などのモデル）
- **乗換案内（のりかえ連携）** — カレンダー・タイムライン右上の電車のボタンで、のりかえ（Yahoo!乗換案内を広告なしで見るアプリ）をひび手帳の中で開き、ひび手帳と同じ見た目で検索。「ひび手帳のタイムラインに追加」で経路が出発〜到着の予定になり、タイムラインでその予定を押すと、乗る電車・番線・乗り換え・運賃・途中の駅が見られる。「のりかえで調べ直す」で同じ区間をすぐ再検索し、そこから追加すると元の予定と入れ替わる（色・持ち物などは引き継ぐ）。のりかえのURLは 設定 → 乗換案内 で変更できる
  - **別の電車** — 経路の予定で、駅から先の電車だけを変えられる。到着が何分変わるか、新幹線・有料特急を使わない電車、「早」「安」「楽」の印も見られる

### お金（家計簿・バイト・ほしいもの）

- **家計簿** — カレンダーの「やること」と「バイト」のあいだの「家計簿」カードから開く
  - 入力：支出／収入、電卓（＋−×÷、オフにもできる）、カテゴリー、メモ（よく使うメモを候補に出す）、日付
  - 一覧：月の収入・支出・合計、日ごとの記録（タップで編集・削除）、前月の繰越金、お金を使わなかった日
  - グラフ：支出・収入のカテゴリー別ドーナツと割合、「月ごと」（カテゴリー別に6か月を比べる）と「今年」（カテゴリーごとの合計と割合）
  - 貯金額：銀行・PayPay・現金など、お金の置き場所ごとに今の残高を手で入れて、どこにいくらあるかを円グラフで表示。置き場所は名前・色を自由に決めて追加・削除でき、合計の移り変わりも線で見られる（家計簿の入力とは別）
  - 予算：残りと「1日あたり使える金額」、カテゴリーごとの予算、いくつかのカテゴリーをまとめたグループの予算（食費＋学食費＋外食費 で月3万円 など）
  - 設定：カテゴリーの追加・名前・色・並び替え・削除、固定費・定期収入（毎月決まった日に自動で記録）、月の開始日（給料日に合わせるなど）、CSVの読み込み（ほかの家計簿アプリから。列は自動で判断し、変えることもできる。金額にマイナスがついたCSVは「マイナス＝支出、プラス＝収入」。UTF-8・Shift_JIS。すでに入っている記録と同じ行は飛ばす（同じファイル内の同じ内容の行はそれぞれ取り込む））、CSVの書き出し、収支のリセット
  - カレンダーの各日の予定の下に、その日の収入（青）・支出（赤）を表示。選んだ日の記録も日付の詳しい表示に出る
- **バイトの給料計算** — カレンダーの下のカード（設定 → 表示 で出す・出さないを切り替え）。バイト先の名前を含む予定をシフトとして数え、時給・深夜割増・休憩・交通費・締め日から見込みを計算。シフトボードのようなリングで、その月の見込み（うすい緑）と、もう働き終わったシフトの分（緑）がたまっていく様子を表示。月間目標を決めると目標を1周として表示。年の合計と年収の目安も
- **ほしいもの** — 「あとで」の右側。欲しいもの（写真・値段・欲しさ・値下がり）、ある金額と最初に欲しかったものとの比較、買ったもの（期間ごとの合計）

### 習慣・集中・アラーム

- **灯（習慣）** — 日記の右上から開く習慣化アプリ
  - 習慣のチェック、「時間」の習慣のタイマー（目標までやりきると、その時間がタイムラインに記録される）、ひとことメモ（Part5を20問 など）
  - 積み重ね（1か月・3か月・半年・1年）、統計、バッジ（連続日数・合計回数）と達成したときのお祝い、長押しドラッグで並べ替え
  - カウンター：ただ数えたいものを＋で数える（今週・合計・1週間の棒つき）
  - 今日の画面とタイムラインに今日の習慣が出て、そこからチェックできる
- **集中タイマー** — タイムライン右上のボタンですぐ始める（予定がなくても、なにをするか・時間・色を選べる）か、予定の画面の「集中タイマー」から開始。全画面の大きな時計（オーロラ／ガラス／カード／フリップ／ロール／ウェーブ／リング／アナログ／ドット／夜明け／光の輪／しずく／めくり板の13デザイン、横向きにも対応）。右上のパレットや 設定 → 表示 から、カラー（8種類＋好きな3色を選べるカスタム）・数字の書体・のこり時間／経過時間・背景の動きを細かく変えられる。環境音、ポモドーロ（25分集中→5分休憩をくり返す）、予定の時間の通知つき。閉じても計り続け、終了すると実際にかかった時間をタイムラインに記録（同じ名前の灯の習慣にも入る）
- **アラーム** — タイムラインで左端から右へスワイプして出すサイドバー。目覚ましを何本でも、時刻・曜日・名前を決めて作れる（鳴るのはアプリ版。音は12種類、スヌーズ、二度寝防止）

### 道具（カメラ・コード・計算機など）

- **カメラ（シャッター音なし）** — 日記の右上のカメラのボタン、またはタイムラインの右端から左へスワイプ。映像の1コマを切り出すので音が鳴らない。3:4 / 1:1、フィルター（フィルム・あたたか・クール・モノクロ・ふんわり）、グリッド、日付の写しこみ、セルフタイマー（3秒・10秒）、前後カメラ切り替え、ズーム（対応機種）、ライト、QRコードの読みとり、SCAN（書類をまっすぐ・白く）。撮ったら「写真だけ日記に追加」か「言葉や気持ちを添える」で日記にでき、「写真アプリに保存」もできる
- **写真をPDFに** — カメラを出した状態でもう一度右端から左へスワイプ。写真をまとめて PDF にする（アプリ版は共有シートで保存）
- **コード** — 日記の右上の QR のボタン。QR・バーコードを作る（テキスト・URL・電話・メール・Wi-Fi・バーコード）、カメラや写真・スクショから読みとる、作ったコードの一覧、**財布**（ポイントカード・会員証のバーコードをアプリの中で描いて、見せるときは画面を最大の明るさに）
- **計算機** — カレンダーの右端から左へスワイプ。履歴つき
- **Mathspace** — 計算機を出した状態でもう一度右端から左へ。数字・数式・条件・可能性を自由に操作できる計算空間。グラフ（式を書くとその場で線に。スライダー・不等式・円などの式・交わる点や山と谷の座標）も
- **チューナー** — ふりかえりの右端から左へスワイプ。チューナー・メトロノーム・コード・純正律。合奏モード、マイクを止めるボタンつき
- **one** — カレンダーの左端から右へスワイプ。今日やることを1つだけ決めるアプリ。決めた1つはカレンダーの「やること」に one の色の丸で入る（完了は両方でそろう）。「言葉」のタブで気になった言葉をメモ・URLつきで残せる
- **しずく** — one の左端から。今日の調子・ととのえる（クイック・プログラム・瞑想・呼吸・ストレッチ）・眠り（星空・眠りの瞑想・眠りの音・タイマー）・学ぶ・記録
- **候 KŌ** — アラームを出した状態でもう一度左端から右へ。七十二候と時刻で色が移ろう、机の上に開いておくための一枚の絵。「遊」ではヨット・ヒット&ブロー・五目並べ・リバーシ・チェス・5五将棋・エアホッケー・ダーツ・数独・大富豪・いろあわせを遊べる（CPU と対戦できる。大富豪といろあわせは CPU 3 人と）

### 見た目

- **テーマカラー／週の始まり（月曜・日曜）** — 設定から変更
- **モノクロモード** — 設定 → 表示。白と黒だけの見た目になり、日記の気持ちや気分のグラフは出なくなる。カレンダーとタイムラインの右下のボタンも日記を書くボタンになる
- **下のバーの透け具合** — カレンダー／タイムライン／日記／ふりかえりを切り替える下のバーを、設定 → 表示 のスライダーで「透明〜不透明」に調節できる（見本つき。「元の透け具合に戻す」でテーマ標準に戻る）
- **起動アニメーション** — アプリを開くと、テーマカラーの上でアイコンの筆記体「h」を書き順どおりになぞり、紺の点がぽんと出てからアプリに切り替わる（約2秒、タップで飛ばせる。設定 → 表示 でオフにできる）

### データ・安全

- **Googleドライブに自動保存** — Googleでログインすると、写真も含めてドライブに自動で保存。新しい端末ではログインして「ドライブから戻す」だけで元に戻せる。日記・写真・場所の記録などを iPhone の中で暗号にしてから送ることもできる（合言葉・復旧キー。move・まいにちも同じ合言葉で読める）
- **バックアップ** — 毎日決めた時刻をすぎると、端末の中に自動で控えを取る（7日分。設定から戻せる）。さらに、毎日／3日ごと／毎週のお知らせで、ワンタップでiPhoneの「ファイル」に保存できる
- **ロック** — 4けたのパスコードとFace IDで、アプリを開くときにロック（すぐ／1分／5分／15分）。日記・場所の記録（MOVE）・家計簿には、それぞれ開くときの鍵もかけられる。人に見られないための鍵で、端末の中のデータの暗号化ではない
- **通知** — 家を出る時刻・明日の持ち物・課題の締め切り・まだ記録していない習慣・予定の前を知らせる（設定 → 通知。ホーム画面に追加したひび手帳で使える）。通知の文はiPhoneの中だけに置き、のりかえのサーバーには時刻だけを送る

## ほかのアプリとの連携

### home（帰るアプリ）から経路を受け取る

home で調べた「現在地から家まで」の経路は、home の「ひび手帳に追加」で予定にできます。

- home とひび手帳で同じ Google アカウントにログインしておく
- home はドライブの「アプリ専用の場所」の `hibi-inbox.json` に経路を置き、ひび手帳は開いたとき・戻ったときにそれを読んで予定に入れる（入れたものは中から消し、同じものは二度入れない）
- 経路の中身は、のりかえの「ひび手帳に追加」と同じ形（予定をタップすると経路が見られ、「別の電車」「のりかえで調べ直す」も使える）

### まいにち（AI）から予定を受け取る

まいにち の AI に「明日15時から17時までバイトを追加して」のように頼むと、確認のあと予定になります。

- まいにち とひび手帳で同じ Google アカウントにログインしておく
- まいにち は home と同じ `hibi-inbox.json` に `kind: "event"` の項目（`{ title, date, start, end, allDay, memo, show, countdown, chrOn }`。`show` は `both`／`cal`（カレンダーだけ）／`tl`（タイムラインだけ））を置き、ひび手帳は開いたとき・戻ったときにそれを読んで予定に入れる（入れたものは中から消し、同じ日・同じ時刻・同じ名前の予定がもうあれば入れない）
- 入るまでのあいだ、まいにち の画面では「追加待ち」として表示される
- まいにち の AI で調べた経路（のりかえ）も、home と同じ `kind: "route"` の項目で届き、経路の予定になる

### move と場所の記録を分け合う

同じ Google アカウントでログインしていると、move とひび手帳の場所の記録をドライブの `hibi-moves.json` で分け合います（どちらで記録・名前つけ・削除しても両方に出る）。

## iOS アプリ版（Capacitor・署名なし IPA）

GitHub Pages 版のファイルはそのままにして、`npm run build` でビルド用の `www/` にコピーし、Capacitor 8 で iOS アプリに包みます。IPA は GitHub Actions の無料 macOS ランナーで作ります（Apple Developer Program なし・署名なし）。iPhone へは AltStore などで個人署名して入れます。

- アプリ名：ひび手帳（Info.plist の表示名は英字の `Hibi`。AltStore が Apple に登録する名前は英数字しか使えないため。日本語の iPhone のホーム画面には `ios-assets/ja.lproj/InfoPlist.strings` の「ひび手帳」が出る）／Bundle ID：`jp.weakestandstrongest.hibi`／iOS 15.0 以上／iPhone 用
- 追加したファイル：`package.json`・`package-lock.json`・`capacitor.config.ts`・`scripts/prepare-web.mjs`（www/ を作る）・`scripts/ios-setup.mjs`（アイコンと Info.plist の設定を入れる）・`ios-assets/`（アイコン一式と、その元の 1024px 画像）・`native/`（iPhone の機能のプラグイン）・`.github/workflows/ios-ipa.yml`・`.gitignore`
- 使うプラグイン：`@capacitor/app`（Google ログインから戻る）・`@capacitor/browser`（ログインを Safari で開く）・`@capgo/capacitor-native-biometric`（Face ID でロックを開く）など
- `www/`・`ios/`・`node_modules/` は毎回作り直すので、リポジトリには入れない
- index.html の中で、アプリの中で動いているとき（`window.Capacitor`）だけ分岐しています。Safari／ホーム画面版の動きは変わりません

### アプリ版で変わるところ

- **Google でログイン**：Safari（アプリの上に重なる画面）でログインし、`jp.weakestandstrongest.hibi://auth/` でアプリに戻ります。のりかえの Worker がこの住所への戻りと、`capacitor://localhost` からの呼び出しを受け付けます
- **のりかえ・駅・道**：のりかえの Worker が `capacitor://localhost` を許可しているので、出発時刻・経路・地図の道が使えます
- **まいにち（AI）**：リポジトリ hibi2 をアプリの中の `hibi2/` に入れて、ひび手帳から今までどおり開きます。AI は iPhone の中で直接動かすこともできます（Apple Intelligence など、まいにち の 設定 → AIのモデル で選ぶ）
- **Face ID のロック**：iPhone の Face ID（ネイティブ）で開きます
- **iPhone の部品**：下のバーと右下のボタンが Liquid Glass に。下から出る画面・確認・メニュー・長押し・時刻ホイール・共有・写真選びも iPhone 本物（設定 → iPhoneとの連携 で元に戻せる）
- **iPhoneとの連携**：iPhone のカレンダーの予定の表示と書き出し、やること・課題とリマインダーの連携、歩数、アプリを閉じているあいだの場所の記録、アラーム、触覚、写真アプリへの直接保存
- **ウィジェットなど**：ホーム画面・ロック画面のウィジェット（カレンダー・次の予定）、ダイナミックアイランド（集中タイマー・出発まで）、ショートカット・Siri、バックグラウンドの更新
- **通知**：iPhone の中で予約するので、オフラインでも鳴ります
- **端から開くアプリ**：日記の左端から Orbit（ブラウザ）、日記の右端から Gyoukai（業界研究）、ふりかえりの左端から Jam（URL は 設定 → iPhoneとの連携）
- **アップデートの確認**：GitHub Pages の版と比べて、新しければ「IPA を作り直して入れ直す」よう知らせます
- **まだ使えないもの**：オフライン用の Service Worker

### Windows 11 で（www/ と iOS プロジェクトを作るところまで）

Node.js 22 以上を入れてから、PowerShell で：

```powershell
git clone https://github.com/weakestandstrongest-sketch/day.git
git clone https://github.com/weakestandstrongest-sketch/hibi2.git   # まいにち（AI）。day の隣に置くと自動で入る
cd day
npm install
npm run build          # www/ を作る（index.html・manifest.webmanifest・sw.js・privacy.html・icons/・startup/・sounds/・vendor/・中で開くアプリのフォルダ、隣の hibi2 があれば www/hibi2/）
npx cap add ios        # ios/ を作る（初回だけ。作り直すときは ios フォルダを消してから）
npm run ios:setup      # アイコンと Info.plist（ログインから戻る URL スキーム・Face ID などの説明）を入れる
npx cap sync ios       # www/ の中身とプラグインを iOS プロジェクトに入れる
```

hibi2 を別の場所に置いたときは、`$env:HIBI2_DIR = "C:\path\to\hibi2"` を設定してから `npm run build` します。iOS のビルド（xcodebuild）は Mac が必要なので、Windows ではここまでです。IPA は次の GitHub Actions で作ります。

### GitHub Actions で IPA を作って受け取る

1. GitHub のリポジトリ → Actions → 「iOS IPA (unsigned)」→「Run workflow」で実行（main のひび手帳のファイルが変わったときも自動で実行されます。まいにち（hibi2）だけを変えたときは、手動で実行してください）
2. 終わったら（緑のチェック）、その実行のページの下にある Artifacts の「hibi-unsigned-ipa」をダウンロード（ZIP の中に `hibi-unsigned.ipa`）。保存は 7 日間
3. `hibi-unsigned.ipa` を AltStore（または SideStore など）で、自分の Apple ID で署名して iPhone に入れる。無料の Apple ID の署名は 7 日で切れるので、AltStore で更新する

### データ

Safari／ホーム画面版のデータとアプリ版のデータは別の場所に保存されます。アプリ版で Google にログインして「ドライブから戻す」を押すと、ドライブに保存してあるデータが入ります（ファイルで移すときは、ホーム画面版の 設定 → バックアップ →「いまバックアップを保存」したファイルを、アプリ版の 設定 →「バックアップファイルから復元」で読み込みます）
